Tra cứu tài sản

Nhập dữ liệu tài sản từ file Excel

Chức năng quản trị: chọn file Excel kiểm kê (định dạng gốc có nhiều dòng tiêu đề cũng đọc được) hoặc file có sheet DATA như mẫu. Web đọc file ngay trên máy này, cho xem trước, rồi mới gửi vào Google Sheet theo từng lô. Khi nhập sẽ cần PIN quản trị.

Cột "Mã tài sản" là khoá chính: không được trống và không trùng. Ở chế độ cập nhật, ô nào trong file để trống thì giữ nguyên giá trị cũ trong Sheet.

Web tra cứu tài sản — dữ liệu lưu trên Google Sheet, quét QR trên tem để tra cứu nhanh.
